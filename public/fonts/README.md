# Report fonts

`Inter-Regular.ttf` and `Inter-Bold.ttf` are embedded into the PDF reports
generated by `src/lib/export/pdf.ts`. They are fetched only when someone presses
**Export → PDF report**, never on page load.

They are here because jsPDF's built-in fonts are Latin-1 only and have no naira
sign (₦, U+20A6) — every amount would print as a blank or a stray glyph. Inter
covers it.
